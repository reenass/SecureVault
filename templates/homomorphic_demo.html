Additive Homomorphism

The product of two ciphertexts decrypts to the sum of plaintexts:

D(E(m₁) × E(m₂) mod n²) = m₁ + m₂ mod n
Use Cases:
  • Sum encrypted file sizes
  • Count encrypted records
  • Aggregate encrypted votes
Scalar Multiplication

Raising a ciphertext to a power multiplies the plaintext:

D(E(m)^k mod n²) = k × m mod n
Use Cases:
  • Apply percentage multipliers
  • Scale encrypted values
  • Compute weighted averages
Paillier Cryptosystem
Key Generation
  1. Choose primes p, q
  2. Compute n = p × q
  3. Compute λ = lcm(p-1, q-1)
  4. Select g = n + 1
  5. Compute μ = L(g^λ mod n²)^(-1) mod n
Encryption
  1. Select random r ∈ Z*_n
  2. Compute c = g^m × r^n mod n²
Public: (n, g)
Decryption
  1. Compute L(c^λ mod n²)
  2. Compute m = L(c^λ mod n²) × μ mod n
Private: (λ, μ)
